# ユースケース

nvecd の機能をひとつずつ軸にした 4 本のガイドです。掲載しているコマンドはすべて実際に動いているサーバーに対して実行し、サーバーが返した応答をそのまま載せています。各ガイドには、そのユースケースで nvecd にできないことにぶつかる箇所も書いてあります。

| ガイド | 扱う内容 |
|---|---|
| [レコメンド](./recommendations.md) | ベクトルも埋め込みモデルも使わず、操作イベントだけで組むレコメンド。 |
| [EC サイト](./e-commerce.md) | 関与度で重みづけしたイベント、商品の埋め込み、適応的な重みづけを伴う `using=fusion`、メタデータフィルタ。 |
| [リアルタイムフィード](./real-time-feed.md) | 高頻度の関与イベント、短い半減期、負のシグナル、メモリ使用量を抑える設定。 |
| [意味検索](./semantic-search.md) | 文書コーパスに対するクエリベクトルからの `SIMV` 検索、ANN 索引の選択、コーパス規模での再現率。 |

最初に読むのは [レコメンド](./recommendations.md) です。もっとも小さい構成で完結していて、残りの 3 本はその語彙を前提にしています。
